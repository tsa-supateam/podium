# ADR 0001: Electron shell + Python engine sidecar

**Status:** accepted

## Context
Podium needs local ML (speech recognition, VAD, pitch, NLP, TTS) and a rich real-time UI (3D audience,
camera preview, charts) on Windows and macOS, with no network access at runtime.

## Decision
- The UI is **Electron + React + TypeScript**. Electron ships the same Chromium everywhere, so camera
  capture, WebAssembly, WebGL and MediaRecorder behave the same on every OS.
- All audio ML runs in a **Python 3.11 sidecar** (`engine/`) because the best offline speech libraries
  (Vosk, faster-whisper, librosa, Parselmouth, NLTK, Piper) are Python-first.
- They talk over a **loopback WebSocket** with a one-time token generated by Electron at launch.

## Consequences
- Two runtimes to package (PyInstaller for the engine is the planned path).
- A clean contract: every message is a JSON envelope (`engine/podium_engine/ipc/server.py`), so either side can be tested alone.
- Tauri was considered (smaller binary). It was rejected because macOS WebKit differs from Chromium for camera and WASM, and a demo-day surprise costs more than a bigger installer.
